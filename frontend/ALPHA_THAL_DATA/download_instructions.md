# Manual Download Instructions for Alpha Thalassemia Datasets

**Target Directory:** `D:\FYP MOHID\frontend\frontend\ALPHA_THAL_DATA`

## Dataset 1: ThalassemiaPBS (Cell Images)
- **Source:** Mendeley Data
- **URL:** [https://data.mendeley.com/datasets/gd9ysj73jd/1](https://data.mendeley.com/datasets/gd9ysj73jd/1)
- **Action:** Click on "Download All" button.
- **Description:** Peripheral blood smear images from thalassemia patients.

## Dataset 2: Thalassemia Dataset (HPLC Data)
- **Source:** Mendeley Data
- **URL:** [https://data.mendeley.com/datasets/p8rv84hrbs/1](https://data.mendeley.com/datasets/p8rv84hrbs/1)
- **Action:** Click on "Download All" button.
- **Description:** Hematological parameters and HPLC data for 1073 patients.

## Dataset 3: Digital Holograms of Normal and Thalassemic Cells
- **Source:** Figshare
- **URL:** [https://doi.org/10.6084/m9.figshare.23549577](https://doi.org/10.6084/m9.figshare.23549577)
- **Action:** Click the "Download all" button.
- **Description:** Digital holographic microscopy images (760 normal + 609 thalassemic RBCs).

## Dataset 4: Alpha Thalassemia Dataset (Carriers VS Normal)
- **Source:** Kaggle
- **URL:** [https://www.kaggle.com/datasets/sriharsha2015/alpha-thalassemia-dataset-carriers-vs-normal](https://www.kaggle.com/datasets/sriharsha2015/alpha-thalassemia-dataset-carriers-vs-normal)
- **Action:** Click "Download" (requires Kaggle account).
- **Description:** Clinical data (288 cases) for carrier prediction with 15 hematological variables.

## Dataset 5: RBCdataset
- **Source:** Mendeley Data
- **URL:** [https://data.mendeley.com/datasets/vhp9m2tt39/1](https://data.mendeley.com/datasets/vhp9m2tt39/1)
- **Action:** Click "Download All".
- **Description:** Red blood cell images from thalassemia peripheral blood smears.
